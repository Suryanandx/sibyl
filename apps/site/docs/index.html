How to set up, use, extend and host Sibyl. Start with Getting started, or search.

Sibyl is a family of open-source products that run in one install and work together: Sibyl Assistant, Sibyl Meet, Sibyl Slides, Sibyl Studio and Sibyl Agents. Each product page links to its docs below.

    Spaces

    • Sibyl Slides

      Sibyl Slides builds slide decks from a prompt, an outline or real data, and lets you edit them in a browser editor. Decks export to PowerPoint (PPTX) and PDF.

    • Media: images, video and audio

      Sibyl makes images, short videos, voice-overs and music with the media models on OpenRouter. Chat is where you make them; Spaces → Media is the library where everything made in the workspace is kept.

    • Monitors

      A monitor keeps an eye on a source for you. When something matters, Sibyl tells you or starts a task. Ask in chat ("tell me when a deal over $50k moves to Negotiation"), or create one on the Monitors
