Sibyl Studio · Open source · Part of Sibyl

Images, video and audio, made in the chat you already use.

Switch the composer from Chat to Image, Video or Audio, pick a model and its settings, and see the price before you make anything. Point at earlier work with @ references. Everything you make lands in Media.

Try it Read the docs

What you can do

Make it in chat

The result opens in the side panel with its prompt, model, settings and cost. Make another, remix it, or use it as a reference for the next one.

Media docs →

Each model's own settings, with the price up front

Aspect ratio, resolution, length, sound and seed, as the model offers them. The estimate updates as you change them.

Media docs →

A library for everything you made

Spaces → Media keeps the images, videos and audio from chat, agents and your team, with filters by type, model and person, favourites and collections.

What it costs to run

There is no subscription. You pay your model provider (through your OpenRouter key) for what you use. These are real numbers we measured; prices move as providers change theirs.

Try it

Sibyl Studio is part of the one Sibyl install, with the other products. You need an OpenRouter API key.

git clone https://github.com/Suryanandx/sibyl.git && cd sibyl && cp .env.example .env && docker compose up --build

Set OPENROUTER_API_KEY in .env, then open http://localhost:3000 and create the owner account. The quickstart on GitHub also covers running it with Node.js.
