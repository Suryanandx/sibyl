Sibyl Meet · Open source · Part of Sibyl

Meetings where people and agents work together, and the notes write themselves.

Start a call, invite people and agents, and talk. An agent can take part, or sit in as a silent note-taker that keeps the transcript, writes the summary as you go and finds the action items. Calls run on LiveKit, which you host yourself.

Try it Read the docs

What you can do

A page for every meeting

Afterwards each meeting has its own page: the overview, key points and AI insight, the transcript, the action items, comments and an Ask AI box. Save the notes to knowledge or share them by link.

Meetings docs →

Agents in the room

Add agents as participants who speak when someone says their name, or as silent note-takers. The people panel shows who is in the call and what each agent is there to do.

Meetings docs →

Every meeting in one place

Upcoming, live and past meetings in one list, searchable by notes and people. Guests can join by link once the host lets them in.

What it costs to run

There is no subscription. You pay your model provider (through your OpenRouter key) for what you use. These are real numbers we measured; prices move as providers change theirs.

Try it

Sibyl Meet is part of the one Sibyl install, with the other products. You need an OpenRouter API key.

git clone https://github.com/Suryanandx/sibyl.git && cd sibyl && cp .env.example .env && docker compose up --build

Set OPENROUTER_API_KEY in .env, then open http://localhost:3000 and create the owner account. The quickstart on GitHub also covers running it with Node.js.
