Sibyl Assistant · Open source · Part of Sibyl

An assistant you talk to, that answers with charts, tables and sources.

Type or talk. Sibyl answers in text and visuals, searches your own files, works in your Google, Microsoft and Slack accounts, and runs routines for you. Anything that sends, changes or spends asks you first. You pay for the AI you use, not for seats.

Try it Read the docs

What you can do

Ask, and see the answer

Replies can be charts, tables, plans, option cards and forms, with the sources underneath. Tap the mic and the same chat becomes a live voice conversation.

Visual answers docs →

Answers from your own files

Add PDFs (scanned ones too), Word, Excel, PowerPoint, web pages, folders and ZIP files to a knowledge base. Sibyl searches them and shows which file and section each answer came from.

Knowledge docs →

Works in your apps, with your approval

Connect Google Workspace, Microsoft 365 and Slack, or anything else through MCP. Sibyl can read and act in them, and every action that changes something shows an approval card first.

Integrations docs →

Routines and monitors that ask before they act

Routines run on a schedule; monitors watch your mail, calendar, files or web pages. What they want to do waits in the Inbox until you approve it.

Routines and monitors docs →

You choose what it costs

Pick a preset (Cheapest, Balanced, Fastest or Best quality) and see the price of 100 messages before you start. Daily and monthly budgets stop spending before it happens.

What it costs to run

There is no subscription. You pay your model provider (through your OpenRouter key) for what you use. These are real numbers we measured; prices move as providers change theirs.

Try it

Sibyl Assistant is part of the one Sibyl install, with the other products. You need an OpenRouter API key.

git clone https://github.com/Suryanandx/sibyl.git && cd sibyl && cp .env.example .env && docker compose up --build

Set OPENROUTER_API_KEY in .env, then open http://localhost:3000 and create the owner account. The quickstart on GitHub also covers running it with Node.js.
